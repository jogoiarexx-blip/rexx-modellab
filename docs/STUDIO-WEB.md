# TRAIN-11B — Estúdio web
A página studio.html é ligada ao editor existente e usa módulos nativos e Web Worker, sem depender do bundle antigo. Abra Foto para 3D, gere um único perfil humanoide em pose T e salve o JSON; no Estúdio carregue esse arquivo ou recupere o rascunho local. Escolha anatomia, rosto, roupas, mãos, animações, gere prévia, inspecione vista/pose e exporte os níveis LOD escolhidos. Há também criaturas estáticas (cão, lobo, cavalo, fera, dragão), adicionadas no TRAIN-11 paralelo.
 
O worker usa prepareCharacter, renderViews, poseProject e exportLOD; os downloads incluem projeto, rig quando aplicável, clips, preensão, GLBs e manifesto de orçamento. Os codecs JPEG existentes foram adaptados a módulos ES nativos, preservando os originais e licenças. Nenhum serviço externo ou upload de fotos. Cancelar termina o worker e descarta a prévia. O rascunho é apenas lido; nunca substituído pelo estúdio. O pacote é entregue em arquivos separados, não ZIP. FBX exige CLI/MCP por enquanto; alinhamento manual em JSON. Não há animação contínua, apenas prévias por pose/tempo, nem editor visual de juntas, nem rig de criaturas. O bundle antigo não foi recompilado. Requer navegador moderno com Web Workers e módulos ES; testes de Node não comprovam compatibilidade real de todos os navegadores.
